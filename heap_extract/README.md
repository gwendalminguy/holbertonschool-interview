## Heap Extract

This project is about extracting the root node of a Max [Binary Heap](https://en.wikipedia.org/wiki/Binary_heap).

* [binary_trees.h](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_extract/binary_trees.h), the header file containing all prototypes.

* [binary_tree_print.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_extract/binary_tree_print.c), helper functions.

* [libheap.a](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_extract/libheap.a), a library of helper functions.

* [1-heap_extract.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_extract/1-heap_extract.c), a function to extract the root node of a max binary heap.
