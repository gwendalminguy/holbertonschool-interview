## Sorted Array To AVL Tree

This project is about working on [AVL Trees](https://en.wikipedia.org/wiki/AVL_tree).

* [binary_trees.h](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/sorted_array_to_avl/binary_trees.h), the header file containing all prototypes.

* [binary_tree_print.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/sorted_array_to_avl/binary_tree_print.c), helper functions.

* [0-sorted_array_to_avl.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/sorted_array_to_avl/0-sorted_array_to_avl.c), a function building an AVL tree from a sorted array.
