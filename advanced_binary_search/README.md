## Avanced Binary Search

This project is about implementing an advanced [Binary Search](https://en.wikipedia.org/wiki/Binary_search) algorithm.

* [search_algos.h](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/advanced_binary_search/search_algos.h), the header file containing all prototypes.

* [0-advanced_binary.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/advanced_binary_search/0-advanced_binary.c), a function finding the first occurence of a given value in a sorted array using binary search.
