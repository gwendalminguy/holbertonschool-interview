## Heap Sort

This project is about implementing a [Heap Sort](https://en.wikipedia.org/wiki/Heapsort) algorithm.

* [sort.h](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_insert/sort.h), the header file containing all prototypes.

* [print_array.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_insert/print_array.c), a helper function.

* [0-heap_sort.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/heap_insert/0-binary_tree_node.c), an implementaion of the Heap Sort algorithm.
