## Linear Skip

This project is about working on [Skip Lists](https://en.wikipedia.org/wiki/Skip_list).

* [search.h](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/linear_skip/search.h), the header file containing all prototypes.

* [skiplist.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/linear_skip/skiplist.c), helper functions.

* [0-linear_skip.c](https://github.com/gwendalminguy/holbertonschool-interview/tree/main/linear_skip/0-linear_skip.c), a function searching for a value in a sorted skip list of integers.
