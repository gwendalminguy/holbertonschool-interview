# Interview

This repository focuses on algorithms implementation for technical interview training.

* [Insert In Sorted Linked List](insert_in_sorted_linked_list/), a function to insert a node in a sorted linked list, in C.

* [Lockboxes](lockboxes/), an algorithm to determine if all lockboxes given as a list can be opened, in Python.

* [Heap Insert](heap_insert/), a function to insert a node in a Max [Binary Heap](https://en.wikipedia.org/wiki/Binary_heap), in C.

* [Minimum Operations](minimum_operations/), an algorithm to determine the minimum number of operations required to transfer text, in Python.

* [Sandpiles](sandpiles/), an algorithm to sum two sandpiles, in C.

* [Linked List Palindrome](linked_list_palindrome/), a function to determine wether a linked list is a [Palindrome](https://en.wikipedia.org/wiki/Palindrome) or not, in C.

* [Log Parsing](log_parsing/), an algorithm to parse logs for server monitoring, in Python.

* [Linked List Cycle](linked_list_cycle/), a function to determine wether a linked list contains a cycle or not, in C.

* [Palindrome Integer](palindrome_integer/), a function to determine wether an integer is a [Palindromic Number](https://en.wikipedia.org/wiki/Palindromic_number) or not, in C.

* [UTF-8 Validation](utf8_validation/), an algorithm to determine wether a sequence of bytes is a valid [UTF-8](https://en.wikipedia.org/wiki/UTF-8) encoding or not, in Python.

* [Slide Line (2048)](slide_line/), an algorithm to reproduce the basic system of the [2048](https://en.wikipedia.org/wiki/2048_(video_game)) famous game, in C.

* [Menger Sponge](menger/), an algorithm to print a two-dimensional [Menger Sponge](https://en.wikipedia.org/wiki/Menger_sponge) of any given level, in C.

* [N Queens](nqueens/), an algorithm to find all solutions for the [N Queens](https://en.wikipedia.org/wiki/Eight_queens_puzzle) problem, in Python.

* [Sorted Array To AVL Tree](sorted_array_to_avl/), an algorithm to build an [AVL Tree](https://en.wikipedia.org/wiki/AVL_tree) from a sorted array of integers, in C.

* [Skip List Search](linear_skip/), an algorithm to search for a value in a [Skip List](https://en.wikipedia.org/wiki/Skip_list), in C.

* [Star Wars API](starwars_api/), a script to interact with an external API, in JavaScript.

* [Rain](rain/), an algorithm to determine a quantity of water retention, in Python.

* [Heap Sort](heap_sort/), an algorithm to sort an array using [Heap Sort](https://en.wikipedia.org/wiki/Heapsort), in C.

* [Heap Extract](heap_extract/), a function to extract the root node in a Max [Binary Heap](https://en.wikipedia.org/wiki/Binary_heap), in C.
